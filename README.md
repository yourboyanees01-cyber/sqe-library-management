# sqe-library-management



\# SQE Library Management System



A library management system developed as part of the Software Quality Engineering (SQE) 

course. This project applies software quality engineering practices — including issue 

tracking, structured project boards, testing, and version control workflows — to the 

development of a functional library management application.



\## Project Overview

The system is designed to help manage core library operations such as book cataloging, 

member registration, and book search/lookup. Beyond the application itself, this repository 

demonstrates a professional GitHub-based development workflow, showcasing how quality 

practices are integrated into every stage of the software development lifecycle.



\## Features (Planned)

\- \*\*Book Management\*\* – Add, update, remove, and catalog library books

\- \*\*Member Management\*\* – Register and manage library members

\- \*\*Book Search\*\* – Search and filter books by title, author, or category
